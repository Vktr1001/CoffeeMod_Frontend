# CoffeeMod ☕️
Specialty coffee e-commerce built by 1001 Labs for the Generation Java Full Stack Bootcamp.

## Core Tech

- **Backend:** Java, Spring Boot 3
- **Frontend:** HTML5, CSS3 (Bootstrap), JavaScript ES6+
- **Database:** MySQL, Spring Data JPA
- **Production Domain:** `coffeemod.shop`

## Local Development

### Backend (Spring Boot)
```bash
# Run the Spring Boot application
./mvnw spring-boot:run

Dev Web Luis Angel
```
