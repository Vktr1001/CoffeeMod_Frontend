## Local Development

### Frontend

El frontend usa módulos nativos del navegador y npm únicamente para administrar Bootstrap e íconos; no usa Vite. Tras clonar el repositorio ejecuta:

```bash
npm install
```

Ese comando actualiza los recursos estáticos de `assets/vendor`. Después abre la raíz del proyecto con Live Server o ejecuta:

```bash
python -m http.server 8000
```

Visitas: `/`, `/views/about-us.html` y `/views/contacto.html`.

### Backend (Spring Boot)
```bash
# Run the Spring Boot application
./mvnw spring-boot:run
```
